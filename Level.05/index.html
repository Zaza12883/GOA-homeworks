#2 შექმენით საიტი GOA-ს შესახებ, საიტზე დაამატეთ თუ რა შეისწავლება GOA-ში, რომელი კურსები არსებობს, როგორი აკადემიაა. დაამატეთ სურათები და გამოიყენეთ ყველაფერი რაც აქამდე ისწავლეთ

Goal-Oriented Academy . GOA (მიზნებზე ორიენტირებული აკადემია)

რა არის GOA?

GOA არის Goal Oriented Academy. ეს არის აკადემია, სადაც მოსწავლეები სწავლობენ პროგრამირებას, ტექნოლოგიებს და გუნდურ მუშაობას.

რას შევისწავლით GOA-ში?

მოსწავლეები ეცნობიან პროგრამირებას,ვებგვერდების შექმნასპრობლემების გადაჭრას და სხვადასხვა ტექნოლოგიას.

კურსები

HTML და CSS - ვებგვერდების შექმნა.

Python - პროგრამირების ენის შესწავლა.

JavaScript - ვებგვერდების ინტერაქტიულობა.

როგორი აკადემიაა GOA?

ჩემი აზრით, GOA კარგი ადგილია ახალი ცოდნის მისაღებად, პრაქტიკული უნარების გასავითარებლად და მეგობრებთან ერთად მუშაობის შესასწავლად.
