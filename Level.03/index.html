პროგრამირების ენები

აქ გაიგებ ინფორმაციას სხვადასხვა პროგრამირების ენის შესახებ.

Python

Python შეიქმნა 1991 წელს.

მისი შემქმნელია გვიდო ვან როსუმი.

Python გამოიყენება ხელოვნურ ინტელექტში, თამაშების შექმნასა და ვებპროგრამირებაში.

JavaScript

JavaScript შეიქმნა 1995 წელს.

მისი შემქმნელია Brendan Eich.

გამოიყენება ვებსაიტების ინტერაქტიულობისთვის და თამაშების შესაქმნელად.

C++ შეიქმნა 1985 წელს.

მისი შემქმნელია Bjarne Stroustrup.

C++ არის კომპილირებადი, ზოგადი დანიშნულების პროგრამირების ენა.

გამოიყენება თამაშების, პროგრამებისა და სისტემების შესაქმნელად.

დღესაც აქტიურად გამოიყენება პროგრამირებაში.
